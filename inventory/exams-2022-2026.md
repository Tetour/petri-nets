### #15 – 2024-25, 2. termín, group E, Q3 (10 b) — the only file with a student solution
- **Source:** `2024-25 - 2. termín E.pdf`, page 2. Header (page 1): skupina E, 20. 1. 2025, 16:00–17:30, D105.
- **Task (verbatim):** "Mějme SHO typu M/M/1. Fronta k lince má to specifikum, že transakce, která je první ve frontě, je netrpělivá, takže po 4 časových jednotkách čekání frontu (a systém celkově) opouští. Systém modelujte Petriho sítí."
- **Category:** (a). Only the head-of-queue transaction is impatient, with a timeout of 4 units.
- **Also asked:** nothing.
- **Solution present:** a hand-drawn net on a gray-shaded background (an overlay added by the uploader). There are **no grading marks or points** anywhere in the file, so I cannot tell if it was judged correct. My reading of the drawing, left to right:
  1. **Generator:** a place with one token (●), linked in a loop with transition T1 labelled "EXP(x)". T1 returns the token to the generator place and also outputs to P1.
  2. **P1:** the queue. P1 → T2 → **P2**, which is "first in queue".
  3. **Head-of-queue lock:** T2 also takes an input from a place with one token (●) drawn below T2. This works as a mutex so only one transaction can sit in P2.
  4. **Seize the line:** P2 → T3. T3 also takes a token from the facility place (● drawn above T3) and outputs to **P3**, "in service". A large arc returns the lock token from T3 to the lower lock place.
  5. **Service:** P3 → T4, labelled "EXP(Y)". An arc returns the token from T4 to the upper facility place. T4 outputs to **P4**, then to T5, the exit transition on the far right.
  6. **Timeout:** P2 also has an arc down to a timed transition labelled "4 j.č." This transition returns the lock token to the lower lock place (inner loop) and outputs to the right toward the exit, apparently into P4 (or T5).
  - **Not marked anywhere:** priorities between T3 and the timeout transition, and capacities.
  - **Legibility:** the drawing is small and low-resolution. The structure above is the most plausible reading. The exact arrowheads (whether the timeout arc ends in P4 or T5, and which loop ends where) are uncertain.
