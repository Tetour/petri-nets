# Petri nets for IMS

Petri net diagrams for the Petri net exercises of the IMS course (Modelování a simulace, FIT VUT), drawn in the course notation and checked by simulation. The notes are in Czech; the scaffolding is in English. The plan is in [PLAN.md](PLAN.md); the raw source inventory is in [inventory/](inventory/).

Start with the notation cheat sheet: [Notace a vzory](notation/Notace%20a%20vzory.md).

## Exercises

Exercises are numbered `TT–NN` (topic – position within the topic) and ordered by topic: basic models, then single mechanisms as in the short exam questions, then marking at time t, then full word problems as at the midterm. Within a topic, newer tasks come first. Where each exercise comes from is written at the top of its note (**Původ**), together with the files it appears in (**Zdroje**). Those paths are relative to the course study folder `IMS - Modelování a simulace/` (outside this repository). The index below is generated by `python3 -m pn.index` from [pn/catalog.py](pn/catalog.py).

Status: `todo` = not built yet; `drafted` = built and passing `make check`, waiting for review; `reviewed` = accepted.

## Layout

```
pn/            Python library: exercise catalogue (catalog.py), README index
               (index.py), net model (net.py), TikZ output (tikz.py),
               lint rules (lint.py), timed token-game simulator (sim.py),
               D/D/x next-event trace (dd.py), build driver (build.py)
notation/      cheat sheet + small pattern nets
exercises/     one folder per exercise, "<TT–NN> - <název>/" containing
               "<TT–NN> - <název>.md" (the note), net.py, net.svg, net.pdf
inventory/     where every exercise comes from (file, page, verbatim text)
build/         generated intermediates (git-ignored)
```

## Building

Requires Python 3.11+, pdflatex with TikZ, and poppler (`pdftocairo`, `pdftoppm`).

```sh
make            # check every net and render net.pdf + net.svg next to each net.py
make check      # checks only
python3 -m pn.build "exercises/09–10 - Kopírovací centrum"   # one net
python3 -m pn.index                            # regenerate the index below from pn/catalog.py
python3 -m pn.dd 3 lifo 1 5 10 10.5            # D/D/3 LIFO trace: events at t1=10, state at t2=10.5
```

What `make check` verifies for each net:

- **Lint:** arcs connect a place and a transition; one parameter per transition; probabilities add up to 100 %; an exit transition exists.
- **Simulation:** a long random run (immediate before timed, priorities, cancelled countdowns, one clock per waiting token) must keep the declared invariants (e.g. *line + in service = 1*), fire every transition, and keep queues bounded where the system is stable.
- **Marking-at-time-t tasks:** the drawn marking must equal the simulated marking at that time.
