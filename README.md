# Petri nets for IMS

Petri net diagrams for the Petri net exercises of the IMS course (Modelování a simulace, FIT VUT), drawn in the course notation and checked by simulation. The notes are in Czech; the scaffolding is in English. The plan is in [PLAN.md](PLAN.md); the raw source inventory is in [inventory/](inventory/).

Start with the notation cheat sheet: [Notace a vzory](notation/Notace%20a%20vzory.md). How the notes and diagrams are written: [NOTE.md](notation/NOTE.md) and [STYLE.md](notation/STYLE.md).

## Exercises

Exercises are grouped into categories, one folder each (`exercises/01 - Základní modely/`, …), and numbered by their position within the category: basic models, then single mechanisms as in the short exam questions, then marking at time t, then full word problems as at the midterm. Within a category, newer tasks come first. Notes refer to each other by the exercise name. Where each exercise comes from is written in the note's last section **Původ a zdroje**, together with the files it appears in and a comparison with existing solutions. Those paths are relative to the course study folder `IMS - Modelování a simulace/` (outside this repository). The index below is generated by `python3 -m pn.index` from [pn/catalog.py](pn/catalog.py).

Status: `todo` = not built yet; `drafted` = built and passing `make check`, waiting for review; `reviewed` = you confirmed the interpretation, marked by renaming the note's section *Interpretace* to *Nápověda* (the index reads the status from that name).

## Layout

```
pn/            Python library: exercise catalogue (catalog.py), README index
               (index.py), note PDFs (notes.py), net model (net.py), TikZ output (tikz.py),
               lint rules (lint.py), timed token-game simulator (sim.py),
               D/D/x next-event trace (dd.py), build driver (build.py)
notation/      cheat sheet + small pattern nets
exercises/     one folder per category, "<NN> - <kategorie>/", and in it one folder per
               exercise, "<NN> - <název>/", containing "<NN> - <název>.md" (the note),
               "<NN> - <název>.pdf" (the same note as a PDF), net.py, net.svg, net.pdf
inventory/     where every exercise comes from (file, page, verbatim text)
build/         generated intermediates (git-ignored)
```

## Building

All tools come from the Nix flake (`flake.nix`, pinned by `flake.lock`): Python, a slim TeX Live with TikZ, poppler, pandoc + xelatex with the DejaVu fonts, and SIMLIB 3.10 built from the official FIT source. Pinned versions keep the committed PDFs and SVGs byte-identical between builds.

```sh
nix develop          # or: direnv allow  (the .envrc loads the shell when you cd into the project)
```

```sh
make            # render every net and note PDF, compile and run the SIMLIB models
make nets       # check every net and render net.pdf + net.svg next to each net.py
make notes      # render every note to "<NN> - <název>.pdf" (A4; task on page 1, hint and net on later pages)
make check      # checks only (nets + SIMLIB models)
make simlib     # compile and run the SIMLIB code of every note that has a SIMLIB section
python3 -m pn.build "exercises/09 - Obsluha zákazníků/10 - Kopírovací centrum"   # one net (or a category)
python3 -m pn.index                            # regenerate the index below from pn/catalog.py
python3 -m pn.dd 3 lifo 1 5 10 10.5            # D/D/3 LIFO trace: events at t1=10, state at t2=10.5
python3 -m pn.dd log 2 fifo 1 4 6.5             # every event from 0 to 6.5
python3 -m pn.dd table 1 fifo 2 4 10            # state table after each event time (D/D/1 tasks)
```

What `make check` verifies for each net:

- **Lint:** arcs connect a place and a transition; one parameter per transition; probabilities add up to 100 %; an exit transition exists.
- **Simulation:** a long random run (immediate before timed, priorities, cancelled countdowns, one clock per waiting token) must keep the declared invariants (e.g. *line + in service = 1*), fire every transition, and keep queues bounded where the system is stable.
- **Marking-at-time-t tasks:** the drawn marking must equal the simulated marking at that time.
